## 기능
참새봇 명령어를 사용하면 다양한 기능들을 살펴볼 수 있습니다.

**명령어 목록**
  - **참새봇 유저 찾기 닉네임**
    ```bash
    참새봇 유저찾기 한참새
    참새봇 유저 찾기 한참새
    참새봇 유찾 한참새
    참새봇 유저검색 한참새
    참새봇 유저 검색 한참새
    ```
    * 결과: "한참새" 닉네임을 가지신 분을 찾았어요! https://playentry.org/profile/65e44d35869cb20f35874599 입니다.
  - **참새봇 정보 닉네임**
    ```bash
    참새봇 정보 한참새
    ```
    * 결과: "한참새"님은 2024. 3. 3. 오후 7:13:09에 생성된 계정으로 총 작품은 47개, 엔이글은 1521개, 노하우 팁은 4개입니다!
  - **참새봇 안녕**
    ```bash
    참새봇 안녕
    참새봇 반가워
    ```
    * 결과: 반가워요! 도움말은 여기를 참고해주세요. https://github.com/seanhan1001/chamsaebot-help
  - **참새봇 한강물 온도**
